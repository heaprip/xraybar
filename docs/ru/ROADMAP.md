## Этап 0 — проверка осуществимости (готово, 2026-09-21)
- Нативный TUN Xray на macOS проверен отдельным PoC на реальном трафике (см. D1–D3).

## Этап 1 — подключение из меню (готово, 2026-09-21)
- Меню: статус, Connect/Disconnect, выбор профиля, выбор набора правил, лог, выход.
- Профили: VLESS (Reality/TLS, raw). Импорт `vless://` из буфера обмена.
- Разовый импорт профилей и наборов правил из v2rayN в режиме только чтения.
- Генератор конфига, повторяющий поведение v2rayN в режиме TUN, покрыт тестами.
- Привилегированный скрипт сессии: запуск xray, установка и восстановление DNS, остановка
  при отключении и выходе из приложения.
- Проверено автором на реальном трафике: импорт из v2rayN, подключение, DNS через туннель.

## Этап 2 — работа с конфигурациями как следует
- ✅ QR: показать сервер в виде QR (Share Server…); импорт сканированием области экрана или из буфера обмена (Vision).
- ✅ Удаление серверов и наборов правил (удерживайте Option в меню). Окон-редакторов нет (решено: не нужны).
- ✅ Собственная копия Xray и файлов `.dat`, загружаемая по запросу и проверяемая по контрольной сумме (данные runetfreedom или Loyalsoldier).
- ✅ Несколько версий Xray рядом; новые релизы по запросу; первое подключение с новой версией —
  пробное, с откатом на последнюю рабочую в одно нажатие.
- ✅ Исключения из туннеля: сети IPv4, которые система маршрутизирует мимо туннеля (Exclude from Tunnel…).
- Другие транспорты по необходимости (xhttp, ws, grpc), другие протоколы — только по запросу.

## Этап 3 — надёжность
- Привилегированный помощник на LaunchDaemon вместо запроса пароля при каждом подключении.
- Учётные данные в Keychain.
- Проверены сон и пробуждение, смена сети, IPv6.
- ✅ Скрипт сборки `.app` с ad-hoc подписью, Open at Login (сделано раньше, не зависит от помощника).
- Developer ID и нотаризация — только при распространении.
